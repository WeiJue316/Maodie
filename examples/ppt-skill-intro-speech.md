# PPT Generator Skill 介绍

## 概述

这是一个将讲稿一键生成乔布斯风极简科技感竖屏HTML演示稿的智能工具。

## 核心特性

- **两种入口模式**：支持从讲稿直接生成，或从主题智能生成
- **极简设计**：一屏只讲一件事，强视觉对比，高留白
- **竖屏比例**：9:16 竖屏格式，适合移动端展示
- **交互丰富**：支持键盘翻页、全屏、缩略图、触摸滑动

## 使用场景

当用户需要以下场景时触发此技能：
- 生成PPT、演示文稿、Slides、幻灯片
- 科技风/极简风/乔布斯风格演示
- 快速制作产品演示、培训材料

## 参数配置

| 参数 | 选项 | 说明 |
|------|------|------|
| 风格 | dark/light/gradient | 深色/浅色/渐变主题 |
| 受众 | 技术/通俗/高管 | 影响语言风格 |
| 时长 | 5分钟/15分钟/30分钟 | 影响内容密度 |

## 生成流程

1. 读取讲稿
2. 生成提炼版讲稿
3. 生成乔布斯风标题
4. 设计幻灯片结构
5. 选择主题风格
6. 生成HTML
7. 质量自检

## 技术特点

- 单个HTML文件，可直接运行
- TailwindCSS + Vue3
- 国内CDN加速
- CSS变量管理主题色彩

## 视觉规范

- 背景：CSS变量 var(--bg-primary)
- 主文字：var(--text-primary)
- 中文字体：Noto Sans SC
- 英文字体：Inter
- 标题字重：font-black/bold
- 正文字重：font-light/normal

## 输出要求

- 每页文字 ≤30 字
- 总页数 8~20 页
- 标题 ≤12 字
- 列表页 ≤5 项，每项 ≤10 字
- 无连续3页以上纯文字
- 每页有 1~3 个光斑装饰

## 快捷键说明

| 按键 | 功能 |
|------|------|
| ← → | 翻页 |
| F | 全屏切换 |
| O | 缩略图概览 |
| N | 演讲者备注 |
| 空格 | 自动播放 |
| 触摸滑动 | 左滑下一页，右滑上一页 |

## 总结

PPT Generator Skill 让你告别繁琐的PPT制作，只需提供讲稿或主题，即可快速生成专业级演示稿。
