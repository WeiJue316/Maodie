Word Skill

Microsoft Word 文档处理的艺术

v1.0.2 · 跨平台支持

适用场景

什么时候使用
Word Skill？

创建 .docx 文件作为主要交付物
需要精确的样式和编号系统
文档包含页眉页脚、目录、页码
涉及批注、修订追踪和评论
需要在不同编辑器间保持兼容
核心原则

把 DOCX 当作
OOXML 来对待

.docx 文件是一个 ZIP 包，
包含多个 XML 文件和资源文件。
结构的重要性不亚于可见文本。

文本可能分散在多个 XML 节点中

样式管理

优先使用
命名样式

✗ 直接格式

直接加粗、设置颜色
文档难以维护和批量修改

✓ 命名样式

标题、正文、引用...
一次修改，全局生效

编号系统

列表编号是
独立的系统

项目符号和编号属于 Word 的编号定义
不是简单的 Unicode 字符
abstractNum、num、段落属性三者协同
"看起来对"不等于编号状态正确
页面布局

布局由
节 (Section) 控制

页边距、方向、页眉页脚
首页不同 / 奇偶页不同
使用节分隔符切换布局
手动空格会导致排版漂移
协作功能

修订、批注、域
需要精确编辑

可见文本 ≠ 完整文档
删除的文本可能仍存在于 XML 中
批注锚点和修订范围容易断裂
目录、页码是域，会缓存旧值
避坑指南

常见陷阱

复制粘贴

会悄悄带入不需要的样式和编号定义

空段落间距

用空行撑间距很脆弱，应设置段落间距

表格自动适应

在 LibreOffice/Google Docs 可能错位

整段替换

可能破坏书签、批注、修订标记

跨平台兼容

交付前
验证兼容性

Word → LibreOffice → Google Docs
表格、页眉、嵌入字体是常见漂移源

.docm 含有宏，高风险
.doc 是旧格式，可能需要转换

使用方法

快速开始

当需要创建或编辑 Word 文档时
任务描述 + .docx 文件即可

Skill 会自动处理：
结构 · 样式 · 编号 · 布局 · 兼容性
