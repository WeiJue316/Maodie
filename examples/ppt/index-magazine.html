Background

ReAct
Agent

给 Agent 一个问题，它不是直接回答，而是会先 Reasoning（思考），然后 Acting（调用工具执行），得到结果后再思考、再行动，循环直到得到最终答案。

核心循环

思考 → 执行 → 思考 → 执行 → ... → 答案

01 tools.py 工具执行
02 cli.py 用户界面
03 session.py 记忆系统

01 · Tools.py

装饰器模式：工具注册机制

代码示例

@tool(
    name="read_file",
    description="读取文件内容并返回",
    schema={...}
)
def read_file(args: dict, ctx: ToolContext) -> str:
    # 读取逻辑
    return content

优势

元信息内聚在函数本身，看到函数就知道它的名称、描述、参数

好处

  • ✓ 不需要到处找配置文件
  • ✓ 自动注册到 TOOL_REGISTRY
  • ✓ 运行时动态改变状态
